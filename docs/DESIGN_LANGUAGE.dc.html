TEXT ON DARK
Three levels, no more. #F2ECFF primary · #9D8FBD secondary · #7E72A6 tertiary. Retire the bare #888 / #777 / #666 / #555 greys scattered through the screens — they read as dead pixels against a violet background.
TINTED FILLS
Selected / owned states use a 12%-mixed tint of their accent, not an arbitrary hex: teal #122B33, pink #2A1030, gold #2A2010, red #2A0D18. Replaces the hardcoded #122b28 / #1c1c3a / #2a1f0a.

03 · SURFACE & SPACE
SPACING
4px base. Use 4 / 6 / 8 / 10 / 14 / 20 only. Panel padding 10 (dense) or 14 (comfortable); gap 8 between siblings, 16 between groups.
RADIUS
4px on panels and buttons. 6px on game cards. 20px on the cash pill. Nothing else — a pixel game shouldn’t look soft.
BORDER
1px hairline is the default and carries state: border color is the status light. 2px reserved for game cards. Dashed = locked.
GLOW
The only elevation. Resting 0 0 6px rgba(accent,0.25), active 0 0 14px rgba(accent,0.8). No drop shadows, no gradients except the card’s vertical panel→panel2.
CRT — THE WHOLE SCREEN, NOT JUST THE ART
The game is played on a CRT, so the tube is the outermost layer of the app — one fixed overlay above every screen, not a per-component effect. Three stacked passes, all pointer-events: none, all mounted once in App.jsx above the router:
01 scanlines — 2px pitch, multiply, 22% black. The existing SCANLINE_OVERLAY, promoted to fixed.
02 aperture grille — 3px vertical RGB stripe, screen blend at 4%. What separates a CRT from a venetian blind.
03 vignette + glass — radial darkening to 45% at the corners, plus a faint top-left sheen.
One overlay for the whole screen — nothing else in the app draws scanlines. Delete every per-component SCANLINE_OVERLAY (TitleScreen, RoadView); three fixed divs mounted once cost one composite layer instead of one per screen. scanlinesEnabled() gates all three at once.
Legibility under the tube — because it now covers text and cards too: 9px floor everywhere, neutral ramp lightened (#888 retired), rules text on its own solid plate, LCD numerals carry a bloom so the 22% line never eats a digit stroke, and no text sits directly on pixel art without a plate behind it. Sprites keep imageRendering: "pixelated".

SUBSTANCE
Card stock is its own surface — a lifted slate-violet #241F4E → #151132, brighter than the #0B0A1E table under it. A 6px hard black bottom edge gives it thickness; no soft shadows.
LEGIBILITY
Nothing under 9px, and rules text sits on a recessed #100E26 strip so it never fights the art. Type name is ink-on-color in the header band — readable even at hand scale under scanlines.
BALANCE
Four fixed bands top to bottom: header, name + affinity, effect, rules. The effect row is a fixed 26px band pinned with margin-top:auto, and the rules footer a fixed 48px at line-height:12px — exactly four lines — so every number in the hand shares a baseline regardless of name length or how far the rules text wraps.
COHESION
One frame, five types. Only the accent changes — header fill, border, affinity chips. Cost pips sit top-right in every type. Unsettled takes violet; grey #666 is gone from the deck.
Highlighted — the only glow in the hand. Lifts 8px, 0 0 16px accent/0.55, matched affinity chip inverts to solid. Exactly one card can be in this state at a time.
Resting — flat in the row, no glow, no lift. Only the 6px black bottom edge. The hand should read as a row of physical cards, with one lit.
Unplayable — opacity 0.5, no cursor. Deck pile shows the current car’s front sprite over a checker stripe, count in LCD — the car is the deck.

05 · VOICE
LABELS SHOUT, PROSE DOESN’T
UI labels are uppercase and terse: RACE, MAINTAIN, OWNED. Explanatory text is sentence case and sounds like a person in a garage — “Rex doesn’t charge extra for the labor, just the AP to make the trip.” Never mix the two registers in one line.
COST IS ALWAYS VISIBLE
Every action states its price before it’s taken, in the same shape: — 1 AP, $80, full service. AP first, cash second, outcome third. A disabled action says what would unblock it.
ICONS
The screens currently mix emoji with pixel art, and emoji render differently on every platform — which breaks the 16-bit illusion hardest on Windows. Migrate them to public/icons.svg symbols at 16×16, keeping the same meanings.

REWORK · STATUS ICONS40×40 — right idea, not yet a set
The right eight glyphs — wrench, check-engine, oil, temp, battery, fuel, tire, warning — but not yet a set. Measured on the delivered PNGs: 244–569 unique colors each (a 16-bit icon should be under 12), content boxes ranging 32×32 down to 34×17 inside the same 40×40 canvas so they read at wildly different weights in a row, photographic shading and per-icon hues with no shared light, and slice bleed from the neighbouring icon on the contact sheet — temperature carried two stray red fragments at x2–5 (cleaned and re-centred here as assets/status-temperature.png; the glyph was also sitting at x19–35, hard right in its own canvas), and oil still has 4 pixels on the edge. The five location symbols have the same problem at three different widths (33 / 44 / 54).
THE SPEC
40×40 transparent canvas, glyph drawn to a 32×32 optical box centred with 4px clear on every side — and optically balanced, so a wide glyph like the wrench sits inside the same visual weight as a tall one like the fuel pump. Max 6 colors: one hue at three steps, the #1A0E2B outline, and one #F2ECFF highlight pixel cluster. Key light upper-left, matching the cars. No gradients, no antialiasing, nothing outside the 4px margin.
HUE BY MEANING
Icons don’t carry their real-world color, they carry their state color, so a row of them reads as one system: teal informational (wrench, tire, battery), orange caution (oil, temp, fuel), red fault (check-engine, warning). Same glyph, same hue, every screen. Regenerate all thirteen in one pass on a single sheet with the palette locked — do not patch them individually.
REWORK · ACTION CARD ART96×120 delivered as finished cards — we only want the art
The illustrations are exactly right; the frames aren’t ours — they bake the type name, the title, the cost pip and the rules line into the bitmap, which can’t be localized, recolored by type, or updated when a card is rebalanced. Cut the object out to a transparent 72×56 art slot and let the card component in §04 draw the frame. Their type colors already match ours: accel green, line violet, brake red, turbo teal, weight gold, grip teal, nitro pink, repair grey.
REWORK · BAKED HUD BITMAPSposition badges, lap counters, timer, leaderboard, status panel
Every one of these is live data drawn as a picture — a PNG per lap count doesn’t scale past three laps, and the status panel’s bars are the wear meter we already built.
